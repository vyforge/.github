## About

Vyforge is a software studio focused on building reliable, modern tools and products.
We work across the stack — backend services, frontend apps, developer tooling, and integrations.

## What we build

- **Backend services** — Spring Boot 4, hexagonal architecture, event-driven systems
- **Frontend apps** — Next.js 16, React 19, TypeScript, modern UI systems
- **Developer tools** — CLIs, SDKs, libraries that make engineers faster
- **Integrations** — APIs, data pipelines, and platform connectors

## Tech stack

`Java 25` · `Spring Boot 4` · `Next.js 16` · `React 19` · `Node.js 24` · `TypeScript` · `PostgreSQL` · `Kafka` · `Redis` · `Docker` · `Kubernetes`
