# @vyforge/i18n — đa ngôn ngữ vi/en cho app Next.js

## 1. Mục đích

Một cấu hình next-intl dùng chung cho mọi app và zone quản trị (`/vi` mặc định, `/en`, múi giờ `Asia/Ho_Chi_Minh` ở cả
server và trình duyệt), dịch lỗi backend theo `code` của Problem Details, và xử lý chuỗi đa ngôn ngữ `LocalizedText`
(`{ vi, en }`) đúng cùng quy tắc fallback với backend (platform-starter-jpa, SQL `vyforge.localized`).

## 3. Tính năng chính

- **`routing`**: `defineRouting` của next-intl với `/vi` (mặc định) và `/en`; `DEFAULT_TIME_ZONE = 'Asia/Ho_Chi_Minh'`.
  Dự án cần ngôn ngữ khác thì tự gọi `defineRouting`.
- **`/server` `createRequestConfig({ routing, messages, timeZone })`**: `src/i18n/request.ts`, locale sai → mặc định.
- **`/proxy` `createI18nProxy()`**: `proxy.ts` chỉ định tuyến ngôn ngữ, không phân quyền (B13/B14).
- **Lỗi backend**: `errorTranslator(t)` tra khoá `code` trong namespace `errors`, thay tham số bằng `params`; chưa có bản
  dịch thì trả `undefined` (dùng message của backend). `platformErrorMessages` (vi/en) cho mã lỗi chung của
  platform-starter-web.
- **`LocalizedText`**: `pickLocalized(value, locale)` (đúng tag → ngôn ngữ gốc `en-US` → `en` → chuỗi fallback → giá
  trị khác rỗng đầu tiên), `pickLocalizedOrEmpty`, `localizedFromForm` (đọc input `<name>.<locale>` của
  `LocalizedTextField`), `localizedLanguages`, `normalizeTag`, `DEFAULT_LOCALIZED_FALLBACK = ['vi', 'en']`. Ca mẫu
  dùng chung với Java (`__fixtures__/localized-fallback-samples.json`).
- **`/schema` `localizedTextSchema({ required, locales, max })`**: zod cùng ràng buộc với Bean Validation của backend;
  lỗi gắn vào `name.vi` để `LocalizedTextField` hiện đúng tab.

## 4. Cách dùng nhanh

```ts
// src/i18n/request.ts
import { createRequestConfig } from '@vyforge/i18n/server';
import { routing } from '@vyforge/i18n';
export default createRequestConfig({ routing, messages: (l) => import(`../../messages/${l}.json`).then((m) => m.default) });
```

```ts
// src/proxy.ts
import { createI18nProxy } from '@vyforge/i18n/proxy';
export default createI18nProxy();
export const config = { matcher: '/((?!api|_next|_vercel|.*\\..*).*)' };
```

```ts
const t = await getTranslations('errors');
const translate = errorTranslator(t);           // truyền cho createFormAction / toFormErrors
const name = pickLocalized(product.name, locale); // { vi, en } → chuỗi
```

## 5. Cấu hình quan trọng

| Tuỳ chọn | Mặc định | Ý nghĩa |
|---|---|---|
| `routing.locales` / `defaultLocale` | `['vi', 'en']` / `vi` | `localePrefix: 'always'` (theo admin-shell) |
| `timeZone` | `Asia/Ho_Chi_Minh` | Format ngày giờ giống nhau ở server và trình duyệt |
| fallback `LocalizedText` | `['vi', 'en']` | Bằng `vyforge.jpa.localized-text.fallback` của backend |

## 6. Tích hợp

`@vyforge/api-client` (`translate`), `@vyforge/ui` (`LocalizedTextField`, `LocalizedText`), `@vyforge/admin-shell`
(`createAdminProxy` gộp CSP + routing ngôn ngữ), backend platform-starter-jpa (`LocalizedText`), mã lỗi i18n vi/en của
từng starter (`i18n/<module>-errors*.properties`) → `@vyforge/<module>/messages`.
